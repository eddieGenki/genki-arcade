## How to ship

1. Open `src/news.ts`
2. Decide which 9 of the existing gaming items to swap (the 4 Genki entries — `welcome`, `covert-dock-3`, `genki-grips`, `shadowcast-cheer` — stay put)
3. Paste the chosen `NewsItem` blocks into `NEWS_ITEMS`
4. `git add src/news.ts && git commit -m "ticker: weekly refresh 2026-05-08" && git push`
5. Cloudflare Workers auto-builds `dist/` and pushes to the edge — live on arcade.genkithings.com within a couple of minutes
